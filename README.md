# fin-code
Finance Lab – Simple explanations for all 16 experiments

Experiment 1: Simulation of N-Period Binomial Model for Stock Prices
"In this experiment, we are simulating all the possible ways in which a stock price can move over a fixed number of periods. First, we give an initial stock price of 100. We assume that in every period, the stock price can either increase by 20% or decrease by 20%. We use U to represent an upward movement and D to represent a downward movement. The code generates all the possible combinations of these upward and downward movements for three periods. Then, it calculates the stock price after every movement and stores all the possible price paths. Finally, it prints all the paths and plots them in a graph. So, the main purpose of this experiment is to see how a stock price can move in different possible ways over multiple periods."

Experiment 2: European Call and Put Option Pricing using Binomial Model
"In this experiment, we are calculating the prices of European call and put options using the binomial model. First, we provide the initial stock price, strike price, upward and downward movement factors, and risk-free interest rate. Using these values, the code calculates the risk-neutral probability, which is the probability used for option pricing in the binomial model. Then, it calculates the stock price when the market moves up and when it moves down. Based on these stock prices, it calculates the call and put option payoffs. Finally, it calculates the expected payoff and discounts it using the risk-free interest rate to get the option prices. In the N-period version, the code first calculates the payoffs at the final period and then works backwards step by step to calculate the option prices today."
Experiment 3: American Call and Put Option Pricing using Binomial Model
"In this experiment, we are calculating the prices of American call and put options using the binomial model. The main difference between European and American options is that European options can only be exercised at the expiry date, whereas American options can be exercised at any time before or on the expiry date. First, the code takes the initial stock price, strike price, interest rate, and other required values. It calculates the risk-neutral probability and generates the possible stock prices at maturity. Then, it calculates the call and put payoffs at maturity. After that, the code moves backwards through the binomial tree. At every step, it calculates two values: the value of continuing to hold the option and the value of exercising the option immediately. It chooses the higher of these two values. Finally, it gives us the American call and put option prices."
Experiment 4: Simulation of a Path of Scaled Symmetric Random Walk
"In this experiment, we are simulating a scaled symmetric random walk. A symmetric random walk means that at every step, the movement has an equal chance of being either positive one or negative one. First, the code generates 1000 random movements using these two values. Then, it calculates the cumulative sum, which means it keeps adding the movements to get the position after every step. After that, we divide the entire random walk by the square root of the number of steps. This is called scaling. We also generate time points between zero and one and include the starting value as zero. Finally, we plot the scaled random walk. The graph shows how the random path changes over time."
Experiment 5: Simulation of a Path of Brownian Motion
"In this experiment, we are simulating a path of Brownian motion. Brownian motion is a continuous-time random process where the movement is random at every small time interval. First, we set the total time as one and divide it into 1000 small intervals. Then, the code generates random values from a standard normal distribution. We multiply these values by the square root of the time interval to calculate the Brownian motion increments. Next, we take the cumulative sum of these increments to get the Brownian motion path. We also add the initial value zero because Brownian motion starts at zero. Finally, we plot the path against time. The graph shows how Brownian motion moves randomly over time."
Experiment 6: Simulation of Stock Price Process Driven by Brownian Motion
"In this experiment, we are simulating how a stock price changes over time using Brownian motion. First, we provide the initial stock price, expected return, volatility, total time, and number of intervals. Here, volatility represents how much the stock price can fluctuate. The code generates random values from a normal distribution and divides the total time into small intervals. Then, it starts with the initial stock price and calculates the next stock price using the previous stock price, expected return, volatility, and random movement. It repeats this process for all the intervals. Finally, it plots the stock price against time. So, this experiment shows how a stock price can randomly increase or decrease over time."
Experiment 7: Simulation of Uncorrelated and Correlated Brownian Motions
"In this experiment, we are simulating two types of Brownian motions: uncorrelated and correlated Brownian motions. First, the code generates two independent sets of random normal values. Using these values, it creates two uncorrelated Brownian motion paths. Uncorrelated means that the movement of one path does not have a linear relationship with the movement of the other path. Next, we use a correlation value of 0.8 to create two correlated Brownian motions. This means that the two paths are positively related and tend to move in the same direction. The code calculates their increments and then takes the cumulative sum to get the paths. Finally, it plots the uncorrelated paths in one graph and the correlated paths in another graph, so we can compare the difference between them."
Experiment 8: European Call and Put Pricing under GBM using Monte Carlo
"In this experiment, we are calculating European call and put option prices using the Geometric Brownian Motion model and the Monte Carlo method. First, we provide the initial stock price, strike price, risk-free interest rate, expected return, volatility, and expiry time. The code generates 100,000 random normal values to simulate different possible stock prices at maturity. Using the Geometric Brownian Motion formula, it calculates the final stock price for each simulation. Then, it calculates the call and put payoffs for all these simulated stock prices. It takes the average of these payoffs and discounts them using the risk-free interest rate. Finally, it prints the estimated European call and put option prices. So, we are using many possible stock price outcomes to estimate the option prices."
Experiment 9: Monte Carlo Pricing of Basket Options
"In this experiment, we are calculating the prices of basket call and put options using the Monte Carlo method. A basket option is an option whose value depends on a group of stocks instead of just one stock. Here, we consider three stocks and assign equal weights to them. First, the code takes the initial prices, volatilities, weights, and correlation matrix of the stocks. The correlation matrix tells us how the movements of the stocks are related to each other. Then, we use Cholesky decomposition to generate correlated random values from independent random values. Using these values, the code simulates the future prices of all three stocks. After that, it calculates the weighted average value of the three stocks, which is the basket value. Finally, it calculates the call and put payoffs, takes their average, discounts them, and prints the basket option prices."
Experiment 10: European Call and Put Pricing under Heston Model using Monte Carlo
"In this experiment, we are calculating European call and put option prices using the Heston model and Monte Carlo simulation. The Heston model is different from the basic Geometric Brownian Motion model because it allows volatility to change over time instead of keeping it constant. First, we provide the initial stock price, strike price, risk-free interest rate, and the parameters required for the Heston model. We also set the number of time steps and simulations. The code starts with the initial stock price and initial variance. At every time step, it generates random values and uses them to update both the stock price and its variance. It also considers the correlation between the random movements. This process is repeated for all the time steps. After simulating the final stock prices, the code calculates the call and put payoffs, takes their average, and discounts them to get the option prices."
Experiment 11: European Call and Put Pricing using Finite Difference Method
"In this experiment, we are calculating European call and put option prices using the finite difference method. Instead of simulating random stock price paths, this method divides the stock price range and time period into small grid points. First, we provide the initial stock price, strike price, interest rate, volatility, and expiry time. Then, the code creates a stock price grid and calculates the final payoffs for both call and put options. After that, it calculates the coefficients required for the finite difference calculation. The code works backwards through time and updates the option values at each grid point using the neighbouring values. It also applies the required boundary conditions for call and put options. Finally, it uses interpolation to find the option prices corresponding to our initial stock price and displays the results. It also plots the call and put option values against the stock price."
Experiment 12: Estimating Returns and Volatilities of Stocks and Portfolio
"In this experiment, we are calculating the returns and volatilities of individual stocks and an equally weighted portfolio. First, the code downloads the past one year of stock price data for Reliance, TCS, and Infosys using the Yahoo Finance library. Then, it calculates the daily returns of each stock by comparing the current day's price with the previous day's price. Using these daily returns, it calculates the annualized returns and annualized volatility of each stock. After that, we create a portfolio by assigning equal weights to all three stocks. The code calculates the daily portfolio returns and then calculates the annualized return and volatility of the entire portfolio. Finally, it displays the individual stock returns and volatilities along with the portfolio return and volatility."
Experiment 13: Short, Medium and Long Moving Averages
"In this experiment, we are calculating and plotting short-term, medium-term, and long-term moving averages of a stock. First, the code downloads one year of historical stock price data for Reliance from Yahoo Finance. Then, it extracts the closing prices. A moving average is basically the average stock price over a particular number of days. Here, we calculate three moving averages: 20 days for short-term, 50 days for medium-term, and 200 days for long-term. The code calculates these averages using the rolling mean function. Finally, it plots the original stock price along with all three moving averages in the same graph. This helps us understand the general trend of the stock price over different time periods."
Experiment 14: Estimating Alpha and Beta for Stocks and Portfolio
"In this experiment, we are estimating alpha and beta for individual stocks and for a portfolio. First, the code downloads the historical prices of Reliance, TCS, Infosys, and the Nifty 50 index. We use the Nifty 50 as the market index for comparison. Then, it calculates the daily returns of all these stocks and the market index. Using linear regression, the code calculates alpha and beta for each stock. Alpha represents the part of the stock's return that is not explained by the market return, while beta tells us how sensitive the stock is to market movements. After that, we create an equally weighted portfolio of the three stocks and calculate its alpha and beta in the same way. Finally, the code displays the alpha and beta values for each stock and for the portfolio."
Experiment 15: Estimating Sharpe and Sortino Ratios for Stocks and Portfolio
"In this experiment, we are calculating the Sharpe ratio and Sortino ratio for individual stocks and for a portfolio. These two ratios help us understand the return we receive compared to the risk we take. First, the code downloads the past one year of stock price data for Reliance, TCS, and Infosys and calculates their daily returns. Then, it takes the risk-free interest rate and converts it into a daily risk-free rate. For each stock, it calculates the excess return by subtracting the risk-free rate from the stock return. Using this, it calculates the Sharpe ratio, which considers overall volatility or risk. Next, it calculates the downside deviation, which considers only negative excess returns, and uses it to calculate the Sortino ratio. After that, the code creates an equally weighted portfolio and calculates its Sharpe and Sortino ratios as well. Finally, it displays the results for all three stocks and the portfolio."
Experiment 16: Testing Lognormal Distribution of Stock Prices using Historical Data
"In this experiment, we are checking whether the stock prices are consistent with a lognormal distribution using historical data. First, the code downloads one year of historical stock prices for Reliance from Yahoo Finance. Then, it extracts the closing prices and calculates the logarithmic returns by taking the natural logarithm of the current price divided by the previous price. After that, it selects a sample of these log returns and performs the Shapiro-Wilk test. This test helps us check whether the log returns approximately follow a normal distribution. The code then checks the p-value. If the p-value is greater than 0.05, it says that the log returns are approximately normal and that the stock prices are consistent with a lognormal model. Otherwise, it says that the test does not support the lognormal model. Finally, it plots a histogram of the log returns to show their distribution."
